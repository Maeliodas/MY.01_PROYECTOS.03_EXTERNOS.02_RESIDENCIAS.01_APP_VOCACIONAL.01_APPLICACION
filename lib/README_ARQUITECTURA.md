# Aevum Iter / APP VOCACIONAL

Base corregida para la evolución del proyecto.

## Incluye
- 11 carreras, incluyendo Arquitectura.
- SQLite local para escuelas, lenguas y carreras.
- Escuela mediante lista desplegable.
- Selección múltiple de lenguas maternas.
- Selección múltiple de lenguas extranjeras.
- Opción de agregar lenguas no incluidas.
- Navegación persistente: Mapa, Resultados y Perfil.
- Base de mapa interactivo con nodos, caminos curvos y estados.
- Personalización inicial de avatar.
- Base preparada para sincronización y actualización institucional.

## Importante
Esta entrega reconstruye la base funcional alrededor de los requisitos consolidados.
Los recursos gráficos exactos de Figma (avatars, ilustraciones, SVG y fondos) deben añadirse en assets/
para alcanzar fidelidad visual completa.
