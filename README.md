# App Vocacional ITTUX V10

Aplicación Flutter de orientación vocacional RIASEC con operación offline-first, SQLite local, backend Node/Express, MySQL/MariaDB y panel administrativo CRUD.

## V10

- Corrección integral de UTF-8/utf8mb4 para acentos y caracteres del español.
- Catálogos relacionales sincronizables: estados, municipios, escuelas, lenguas, idiomas, preguntas y carreras.
- Lenguas/idiomas personalizados permiten continuar de inmediato y generan una sugerencia para aprobación administrativa.
- Editor de avatar en pantalla separada con avatares incluidos, galería y cámara.
- Pregunta abierta asociada a cada carrera.
- Top 3 de carreras con enlaces oficiales de TecNM/Tec de Tuxtepec cuando están disponibles.
- CRUD y filtros en el panel web.

Consulta `INSTALACION_VERSION_10.md` antes de instalar.
